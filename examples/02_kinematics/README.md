# 运动学实验室：草稿式运动示意动画与 LaTeX 公式

目标是验证“像解题草稿一样直观地表现运动，同时让草稿动起来”。默认视图以地面、小球、运动残影和速度箭头表现竖直上抛；函数曲线成为可选辅助视图。当前只实现抛体这一类具体题型，不预先设计通用物理引擎、场景编辑器或自动解题系统。原来的 `01_cube` 不受影响。

![来自实际 Vulkan 渲染帧的动画](../../docs/kinematics-sketch.gif)

## 启动与操作

在项目根目录运行：

```powershell
.\build\vs2022\bin\02_kinematics\Release\vulkan_kinematics.exe
```

或者选择 CMake 启动目标 `vulkan_kinematics` 后在 VS Code / Visual Studio 中调试。构建命令见根目录 README；当前示例自身不需要额外运行时着色器文件，Dear ImGui 后端内嵌其 Vulkan 着色器。

| 步骤 | 新出现的信息 | 应观察的关系 |
| --- | --- | --- |
| 1. 建立模型 | 坐标系、起点、初速度与角度 | 原点、正方向和初始高度如何规定 |
| 2. 分解初速度 | 水平/竖直分量、辅助线和分解公式 | 两个分量组成同一个初速度矢量 |
| 3. 合成运动 | 轨迹、运动点、投影线、瞬时速度与两个函数图像 | 同一个 t 对应同一组 x、y、vx、vy |
| 4. 求解与检验 | 最高点、落地点、落地条件、飞行时间和射程 | 用 y(T)=0 求 T，再用 x(T) 求射程 |

程序默认使用 `15 m/s、90°、地面起点`，进入第 3 步并从起点播放竖直上抛，普通演示速度为真实时间的 0.6 倍。点击“暂停”或按空格暂停；到落地自动停下，再次播放会回到发射时刻。数字键 1–4 切换步骤，Esc 退出。手动进入第 1/2 步回到起点，进入第 3/4 步暂停在最高点供观察。

“草稿示意”默认开启：不画网格坐标轴，以地面剖面线和少量标注交代物理场景。蓝色实心球是当前物体，淡色残影是它最近经过的位置，空心标记是初始位置或最高点，不是额外的物体。蓝色速度箭头随速度缩短、归零和反向，灰色箭头保留初速度作比较；紫色重力箭头方向不变。

右侧横线连接初始与当前状态，表达时间段内的状态变化；它不表示物体水平运动，也不按路程比例绘制。运动路径与速度箭头职责不同，不能用同一个箭头同时代表二者。

“关键位置”控制初始/最高点标记及参考路径；“函数图像”默认关闭，开启后恢复位置和速度曲线；取消“草稿示意”可回到原坐标视图。四个步骤的坐标分解细节仍可在原视图中观察。

拖动时间轴或在任一函数图像中点击、拖动可以定位时刻并暂停。`±0.05s` 用于精细观察，“最高点”“落地”直接跳到事件时刻，“慢放”以 0.25 倍速度播放。可关闭速度/加速度示意；原坐标视图还可关闭位置投影线。

可调整 `v0`（5–35 m/s）、抛射角 `a`（0–90 度）、发射高度 `h0`（0–15 m）。参数改变时，本步骤的时间位置重新初始化，避免新旧条件混用。固定 `g=9.8 m/s²`。提供斜抛、平抛、竖直上抛三种预设。

窗口最小尺寸约为 1100×780；内容不足以完整显示时可滚动。推荐使用初始窗口尺寸或最大化。

## 模型、公式与语义

模型假设：质点、恒定重力加速度、无空气阻力、水平地面、起点 `(0,h0)`、地面 `y=0`、向右与向上为正。抛射角目前限制在第一象限，不包含向左或向下发射。

```text
vx0 = v0 cos(a)                 vy0 = v0 sin(a)
x(t) = vx0 t                   y(t) = h0 + vy0 t - g t²/2
vx(t) = vx0                    vy(t) = vy0 - g t
T = [vy0 + sqrt(vy0² + 2 g h0)] / g
R = vx0 T                      H = h0 + vy0²/(2g)
```

界面中的角度是度，计算时转换为弧度，正式排版公式使用 θ 表示角度。模型用解析式在指定时刻直接求值，不用逐帧积分累积位置。当前默认竖直上抛的飞行时间约 `3.061 s`，最高高度约 `11.480 m`，水平射程为零。点击“斜抛”预设切换到 `v0=20 m/s, θ=45°, h0=0` 时：`T≈2.886 s, R≈40.816 m, H≈10.204 m`。

这里的 `y(t)` 是竖直坐标/高度，竖直位移应为 `y(t)-h0`；两者都不是路程。`x-y` 运动轨迹和横轴为 `t` 的函数图像明确分开。位置图共用米为单位的纵轴，速度图共用 m/s 为单位的纵轴。[OpenStax：抛体运动与方向分解](https://openstax.org/books/university-physics-volume-1/pages/4-3-projectile-motion)

最高点 `vy=0`，一般仍有非零 `vx`；在竖直上抛的特殊情况下合速度才会在最高点为零。起落高度不同时，不能直接使用 `T=2vy0/g`。

轨迹坐标按米等比例绘制，屏幕上向下的 Y 轴由绘图映射翻转；物理公式仍使用向上为正。速度箭头使用独立的统一比例，不代表位移。紫色 `g` 箭头表示加速度方向，不与速度箭头共用量纲或比例。

“落地”显示的是碰撞前瞬间的状态，因此速度可以非零。demo 不模拟接触、碰撞或反弹。地面水平发射的退化情况 `h0=0, a=0` 给出 `T=0`，显示说明而不伪造一个时间区间。

## 当前代码边界

- `model.hpp`：纯 C++ 参数、解析运动状态、关键事件与播放时间。不依赖 Windows、ImGui 或 Vulkan。
- `lesson.cpp / lesson.hpp`：具体斜抛题的四个步骤，以及轨迹、箭头、坐标轴、曲线、文字、控制项的程序化绘制。
- `sketch.cpp`：草稿式运动场景及两个时刻的状态关系图，和坐标视图共用同一个运动模型及时间。
- `src/math/formula.hpp`：把已排版的公式加入 ImGui 图集并显示；`assets/formulas/` 保存共用的 LaTeX 源公式、生成脚本和缓存。
- `main.cpp`：示例入口与教学测试钩子；Win32 窗口、Vulkan 生命周期和 ImGui 后端位于共用的 `src/platform/vulkan_host.cpp`，与正式编辑器复用，立方体仍为独立实现。
- `model_test.cpp`：可脱离 GPU 运行的物理与时间控制测试。
- `third_party/imgui`：固定版本 Dear ImGui；图形、文字和控件由其 Vulkan 后端提交到 GPU，不使用网页或视频播放代替绘制。

这里只做了必要的代码分离。尚未把“解题步骤”“标注”“公式绑定”做成通用数据格式，也没有跨示例提取渲染框架。渲染层采用单帧在途和保守的窗口资源重建，以降低原型阶段的同步复杂度。

## 对术语与方案的判断

你的“程序化绘制物理图像”表达可以理解；为减少歧义，进一步可区分“运动示意图”“物理量—时间图像”和“解题过程可视化”。它们需要的数据与交互不同。

“先做 demo 验证，再决定封装”是合适的顺序。现阶段不需要刚体物理引擎；解析运动学模型更容易核验题目条件与公式。运动学描述运动，本例把重力加速度作为已知模型条件，没有实现从任意受力关系自动推导方程的动力学求解。

这个 demo 已能为特定题型计算结果，但仍不是通用求解器。若将来支持任意题目，题目结构化、模型选择、约束求解和图形表达需要分别考虑，不能把一段播放动画等同于自动解题。

## 先确认效果，再决定的封装方向

先用这版确认三件事：逐步显隐是否清楚；公式是否需要逐行代入或高亮；时间联动是否有助于理解解题。

如果效果符合预期，下一步可以仅提取已经重复的少量对象：带单位的运动状态、步骤中的可见元素、坐标映射，以及点/箭头/辅助线/曲线/公式标注。选第二个题型（例如匀变速直线运动）验证这些对象是否真的通用，再决定是否需要场景图或声明式描述。此处只记录候选方向，没有提前实现框架。

## 验证方式

新版额外验证公式缓存解码及图集边界、窗口重建后的公式纹理生命周期、普通箭头字符、草稿/坐标/曲线视图切换和上升/下落速度方向。查看了小窗口、平抛落地、竖直最高点的实际渲染截图，并检查上升与下落在相同高度的对照帧。`--capture-animation` 确定性输出覆盖一次完整竖直上抛的 90 帧后退出，配合 SDK 截图层用于生成预览；程序本身不会把这些帧写成图像文件。GIF 使用 60 ms 每帧放慢展示并循环，应用实际运行到落地会停下。

```powershell
ctest --preset debug -R kinematics --verbose
ctest --test-dir build/vs2022 -C Release -R kinematics --verbose
```

数学测试覆盖同高斜抛、平抛、竖直上抛、零飞行时间、非法参数、落地、最高点、能量一致性、位置导数与速度关系，以及拖动暂停/慢放/到时停止。

GPU 冒烟测试在真实窗口中绘制 120 帧，通过 ImGui 输入事件点击步骤按钮，验证导航到求解步骤；覆盖窗口大小变化、最小化恢复，并绘制平抛落地、竖直上抛、零时间区间和高起点低速度的边界场景。参数边界场景通过程序设置，不能据此宣称所有参数控件均已完成外部鼠标测试。

启用 Vulkan 验证层和同步验证。调试版全项目四项测试通过，发布版运动学两项测试通过；最终运动学运行均为 **0 个验证错误、0 个警告**。额外截图运行启用 LunarG 截图层时，会出现两条 loader 的层加载提示，与正式测试分开统计。

运行与截图在本机 RTX 4060 Laptop GPU、Vulkan SDK 1.4.341.1、MSVC 19.41.34120 上验证。尚未验证其他设备、长时间运行、碰撞、空气阻力、自然语言输入或图示导出。
