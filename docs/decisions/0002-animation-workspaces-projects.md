# ADR 0002：动画工作区与独立工程

状态：已实现并验证，2026-09-08。

本轮完整目标是界面/交互重组、非线性及突变动画编辑、独立工程持久化，不以只增加一种公式动画作为完成。

## 设计

- 布局和动画工作区共享同一个 Workspace/Document；切换仅改变面板配置。参考 Blender 的工作区、对象树、属性区和底部时间轴，保留二维物理示意的阅读需求。
- 动画是确定性的时间到属性映射。支持公式驱动、连续的线性/平滑关键帧、阶跃关键帧和明确分段公式。跳变由工程数据描述，不必修改/重新编译 C++。
- 公式用安全的有限表达式语言。动画三角函数采用弧度；原有组件几何表达式的角度语义保持兼容。命名物理量如 F 的单位用于标注，须明确映射到位置、箭头长度等显示属性；不声称自动完成牛顿方程求解。
- 独立工程保存主场景、组件定义/实例、草稿与其独立历史、动画、播放/工作区状态及必要资源信息；场景 JSON 继续作为导入/导出交换格式。重新打开工程应保留历史游标、撤销与重做，且不能依赖原项目目录中的临时 history 文件。
- 加载先在临时工作区完整验证，成功后一次切换。保存采用同目录临时文件与原子替换；失败不破坏原工程。

## 验收

- [x] Blender 风格的紧凑中性界面、可调面板分隔、布局/动画工作区与清晰对象树。
- [x] 公式、命名物理量、分段突变与关键帧动画，有可编辑曲线/关键帧和时间定位。
- [x] GUI 与 MCP 使用同一动画命令，撤销/重做及真实窗口同步。
- [x] 独立工程保存/重开/移动路径后，场景、组件、动画与历史完整保留。
- [x] 旧场景可导入；资源缺失、错误公式、损坏工程有明确错误，不导致崩溃或部分覆盖。
- [x] 实际示例、核心/GUI/MCP 验证、Debug/Release 同步检查、截图、用户/维护文档及 Git 提交。

参考：[Blender 工作区](https://docs.blender.org/manual/en/latest/interface/window_system/workspaces.html)、[Timeline](https://docs.blender.org/manual/en/latest/editors/timeline.html)。
