完整目标、实现边界和验收依据见 [ADR 0002](decisions/0002-animation-workspaces-projects.md) 与 [使用说明](animation-and-projects.md)。本轮已完成布局/交互、动画编辑、独立工程、Debug/Release 实测和文档；验收详情见 ADR 0002。

# 开发计划与验收范围

v0.2 已完成目标：将“斜面接圆弧”的题目作为真实案例，实现参数化组件与独立编辑历史，并让历史可在前端拖动回溯。目标不会以“能勉强拼出图片”替代可维护的编辑能力。

## v0.2 验收清单

- [x] 圆弧图元有圆心、半径、起止角，绘制与拾取正确。
- [x] 组件定义包含内部图元、局部坐标、公开参数和参数约束，可保存和复用。
- [x] 场景组件实例作为整体选择、移动、旋转和缩放，内部图元随整体变换。
- [x] 组件编辑有独立画布/文档/撤销栈/日志，主场景编辑与组件编辑互不消费对方历史。
- [x] 修改组件草稿不悄悄改变主场景；通过显式发布/更新操作应用组件定义版本。
- [x] 历史列表支持选中状态；历史滑块支持回溯预览，退出预览恢复当前状态，恢复旧状态是可撤销的新命令。
- [x] 物理播放时间和编辑历史游标分别显示与控制。
- [x] MCP 支持明确的文档范围，能编辑组件与场景并查询各自历史/预览状态。
- [x] 题目示意有 A/B/C/D/E/O/P、相切斜面/圆弧、粗糙区间、同高辅助线、半径/长度/角度标注，改变 R/L/倾角能保持几何关系。
- [x] 核心、GUI 和 MCP 测试覆盖实例复用、参数校验、隔离历史、历史拖动与主场景发布行为。
- [x] Debug / Release 构建及相关 Vulkan 同步验证通过；检查实际窗口截图。
- [x] Git 基线与功能提交齐全，开发文档与实现一致，无构建缓存/本地日志进入版本库。

## 后续方向

沿任意轨道的运动、摩擦/脱轨等物理约束需要单独的动力学模型。组件表达几何与参数，不自动成为物理求解器。后续再评估组件嵌套、库发布策略、自动布局、任意 LaTeX 即时排版和多用户协同。
